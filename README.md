# 🎓 Student-Management-System-Project
A full-stack Spring Boot web application for managing student records with secure login, registration, CRUD operations, and token-based password reset functionality.

A comprehensive web-based application built with **Spring Boot** and **Thymeleaf** to efficiently manage student records, authentication, and password recovery.

## ✨ Features

- **User Authentication** – Secure login with email and password validation.
- **Student Registration** – Add new students with personal and academic details.
- **Dashboard** – View all student records in a responsive, sortable table.
- **CRUD Operations** – Create, Read, Update, and Delete student profiles.
- **View Student** – Dedicated detail page for each student.
- **Forgot Password** – Token-based password reset (simulated email with console link).
- **Responsive UI** – Built with Bootstrap 5 for a clean, mobile-friendly interface.

## 🛠️ Tech Stack

| Layer       | Technology                              |

| Frontend    | Thymeleaf, HTML5, Bootstrap 5, CSS       |
